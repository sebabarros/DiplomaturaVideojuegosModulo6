# Presentación web · Clase 1

La presentación funciona sin instalar dependencias. Abrí `index.html` en un navegador; la portada dirige automáticamente a `clase-1.html`.

## Controles

- Flechas, espacio o botones inferiores: avanzar y retroceder.
- `O`: vista general.
- `N`: notas docentes.
- `F`: pantalla completa.

## Publicación en GitHub Pages

1. Subir estos archivos a la raíz del repositorio.
2. En GitHub, abrir **Settings → Pages**.
3. Elegir **Deploy from a branch**.
4. Seleccionar la rama principal y la carpeta `/(root)`.

GitHub mostrará la dirección pública cuando termine la publicación.

## Adaptación

- El contenido editable de la clase está en `clase-1.html`.
- `index.html` funciona como entrada para GitHub Pages.
- Colores, tipografías y disposición están en `styles.css`.
- La navegación está en `script.js`.
- Cada diapositiva es una etiqueta `<section class="slide">`.
- Las notas privadas del docente están dentro de `<aside class="speaker-notes">`.
